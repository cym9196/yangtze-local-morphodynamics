# 长江局部三维动床—铁块冲淤机理模型

仓库中每个文件的作用和目录关系见 [文件作用说明_中文.md](文件作用说明_中文.md)。

这是一个可复现的 OpenFOAM v2412 研究基线：`0.50 m/s` 来流作用于可冲淤
石英砂床上的均质铁块，铁块可平移、转动和倾覆。计算先进行 3 s 水动力
启动，然后进行 60 s 的水流—输沙—床面—刚体耦合，总结束时刻为 63 s。

该模型面向“局部机理研究”，不是未经率定即可代表任意长江河段的工程预报模型。
所有选值、单位、来源性质和建议范围都列在
`parameters/model_parameters.csv`，以后用现场 ADCP、床沙筛分和冲淤测量替换即可。
观测依据与模型原始文献见 `REFERENCES.md`；`validate_case.py` 会检查参数表、
字典和几何推导是否发生不一致。

实验体尺寸为 `0.05×0.05×0.10 m`：床面以下为 `0.05 m` 可动砂层，床面以上
为 `0.05 m` 水体。铁块为 `0.01×0.01×0.02 m`，底面立在初始床面中央，
顶部距水面 0.03 m，因此初始完全浸没。

## 1. 已实现的物理过程

- 三维不可压 RANS，`k-omega SST` 湍流模型；
- Meyer-Peter 推移质、Soulsby 临界 Shields、床坡修正和雪崩修正；
- Fredsoe 沉速和悬沙对流扩散；
- Exner 方程更新真实床面高程，`morphoAccFactor=1`；
- 解析长方体浸没边界，不在流体网格里挖空，所以移动时不会撕裂床面；
- 六面 54 点、方向投影加权的并行 Winkler–Coulomb 接触：直立时使用
  `0.0001 m²` 底面，侧倒后自动使用 `0.0002 m²` 长侧面；浮力、重力、床面承载、
  阻尼、静/动摩擦与流体力共同驱动六自由度平移、滚动和倾覆；接触法向取
  冲刷坑最近面元的实时法向，而不是固定竖直方向；
- 3 s 启动期间床面和铁块均锁定，避免初场瞬时冲击。
- 5 cm 短试验段设置只作用于铁块的水平柔性限位框，范围为
  `x,y=0.003–0.047 m`：铁块仍可在域内平移、滚动和倾覆，同时平滑浸没边界
  不会碰到入口、出口和侧壁；水流边界保持开放；
- 六自由度运动加入线性 `0.05 N·s/m` 和角向 `3e-5 N·m·s/rad` 阻尼，
  分别对应约 0.31 s 和 0.02 s 衰减时间，用于解析厘米级铁块的实际耗散；
- 悬沙体积分数强制限制在 `0–0.60`；Exner 床面变化同时限制为每步
  `0.001 mm` 和每秒 `0.5 mm`，并用 4 次守恒邻域体积交换平滑每步增量，
  防止局部床面曲率累积后破坏动网格；该滤波不直接平滑累计床面；
- 每个输出时刻在各并行分区保存 `immersedBodyState`，续跑会恢复铁块位置、
  姿态、速度、加速度、角动量和力矩，而不是回到初始直立状态；
- 移动网格后将 `k/omega/nut` 限制在宽松的物理区间，避免单个畸变单元触发
  RANS正反馈；正常解远低于这些上限，因此它们只作为失稳保险丝；
- 每个输出时刻自动记录床面 `y+`、床面剪切应力以及 `U/p/k/omega/Cs/bodyMask`
  极值，用来识别壁函数失配、浓度越界或数值发散。

尚未实现的过程包括自由表面波浪、非均匀多粒径分选、黏性泥、孔压液化、
颗粒逐粒碰撞和弹塑性深埋。它们不能靠多填几个常数自动出现，分别需要
VOF、多组分输沙、黏沙本构或 CFD–DEM/多孔介质接触模型。

## 2. 全域 1 mm 网格

运行 `make_variable_mesh.py` 会生成一个完全正交、无分级接口的六面体块：

- `x=0–0.05 m`：50 个单元；
- `y=0–0.05 m`：50 个单元；
- `z=0–0.05 m`：50 个单元；
- 全域单元边长严格为 1 mm；
- 总量 125,000 个体单元、2,500 个有限面积床面面元。

这比只在铁块附近加密的旧基线多约 3.5 倍单元，但不会让远场粗网格控制压力
误差或让铁块尾涡穿过分级接口，适合作为60秒机理模型的统一网格基线。

## 3. 关键物性与初始条件

- 水：15 ℃，`rho=999 kg/m3`，`nu=1.14e-6 m2/s`；
- 水深：0.05 m；流速：0.50 m/s；湍流强度：5%；
- 床沙：石英 `rho_s=2650 kg/m3`，代表性 `d50=0.23 mm`，孔隙率 0.40，
  休止角 32°，等效粗糙度 `Ks=2.5*d50=0.575 mm`；
- 铁块：`0.01×0.01×0.02 m`，密度 7870 kg/m3，质量 0.01574 kg；
- 铁块中心初始位于 `(0.025,0.025,0.010) m`，完全浸没；浮力每步按浸入
  水体网格内的 `bodyMask` 体积积分，可随平移和倾覆自动变化；
- 接触基线：静摩擦 0.52、动摩擦 0.42、地基刚度 5 MPa/m、阻尼比 1.2、
  承载上限 18 kPa；这些接触量必须用湿砂承载/拖曳试验率定；
- 物理时间：Shields 系数 1、形态加速 1，不使用演示性放大。

长江悬沙常含比床沙细得多的冲泻质。当前求解器是单粒径，不能把约
`0.01 mm` 的悬沙粒径和 `0.23 mm` 床沙错误合成一种粒径。因此基线入口
悬沙为零，只模拟床沙自身起悬；0.10、0.16、0.32 kg/m3 三个观测情景已
记录在参数表，待多组分模型中启用。

## 4. Ubuntu 上逐步运行

下面每个脚本内都有注释，任一步失败都会停止，不会继续产生伪结果。

```bash
# 第一步：进入算例
cd /media/cym/292522a9-3bf5-4fc2-bafa-29464300b1e3/sed-0.01/OpenFOAM/cym-v2412/run/yangtzeIronBlock3D_1mm60s

# 第二步：编译自定义浸没边界/接触耦合求解器（首次或源码变化后）
cd solver/immersedSedExnerFoam
./Allwmake
cd ../..

# 第三步：只生成网格并检查体网格和有限面积床面
./Allmesh
grep -E "cells:|Max aspect|Mesh OK" log.checkMesh
python3 validate_case.py

# 第四步：6 核完整计算。存在分区断点时自动续跑，否则新建计算。
# 推荐后台运行，断开 SSH 后仍会继续。
./launch_background.sh

# 第五步：查看进度；Time 是当前物理时刻，最终应为 63。
tail -f log.immersedSedExnerFoam.63s

# 随时查看是否在运行、最新物理时刻、耦合进度和剩余磁盘
./status_run.sh
```

`Allrun63s` 每 2 s 以二进制保存一次分区结果，并只重构最终时刻，以避免当前
Ubuntu 的磁盘被写满。脚本会在可用空间不足 5 GiB 时拒绝启动。计算中断后
不要重新建网格；`launch_background.sh` 会自动识别已有分区断点并调用续算脚本，
也可以前台直接运行：

```bash
NPROCS=6 ./Allresume63s
```

`set_decomposition.py` 会自动采用只沿水平面划分的 `3×2×1` 分区，因此 6 个
进程都贯穿水深并拥有床面面元。实测 12 个超线程反而比 6 个物理核心慢，
本机默认值保持为 6；若使用集群，8 核会自动生成 `4×2×1`，但应先测试并行收益。

全域1 mm网格的0.2 s立即释放压力测试耗时约5分58秒、内存峰值约
143 MiB/进程。按约315,000步线性外推，63 s正式计算约31小时；考虑后期床面运动、
写盘和最终重构，应预留36–48小时连续运行窗口。集群上从算例目录提交前，先根据站点
修改 `hpc/submit_slurm.sh` 的账户、分区和 OpenFOAM 环境；默认模板申请 8 核、
16 GiB 内存和 3 天。正式提交前应先把 `endTime` 暂改为 0.1 s 做强缩放测试。

```bash
sbatch hpc/submit_slurm.sh
```

## 5. ParaView 查看与视频

打开 `yangtzeIronBlock3D_1mm60s.foam` 时选择 **Decomposed Case** 可直接播放
全部分区时刻；用 `Contour` 对 `bodyMask=0.5` 得到封闭铁块。床面是真实毫米级
变形，显示时可用 Warp By Scalar 放大，但定量读数必须使用未放大的坐标。

若需要现有实体砂层渲染脚本，先确认至少还有约 15 GB 空间，再执行：

```bash
reconstructPar > log.reconstructPar.all 2>&1
./postprocess_solid.sh
```

生成的 `metrics.csv` 给出每个时刻的最大冲刷、最大淤积和铁块运动；
`frames_solid/` 用实体厚度显示沙层，而不是把 Exner 床面误看成一张薄片。

## 6. 率定与论文使用顺序

1. 用无铁块平床流速剖面率定入口湍流和床面粗糙度；
2. 用静水沉降/拖曳试验率定摩擦、刚度、阻尼和承载力；
3. 用固定铁块冲刷试验率定起沙、床载和悬沙参数；
4. 最后才释放铁块，比较冲刷坑、淤积丘、位移和姿态；
5. 至少做网格、时间步、粒径、摩擦和来流强度敏感性分析。

只有通过上述验证后，结果才适合写作定量结论。当前工程首先提供统一、可追踪、
能复现实验机制的数值基线。
